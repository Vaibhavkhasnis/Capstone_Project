# Inside the Vault: Cracking the Code of Corporate Domain Secrets

## Active Directory Security Assessment Lab

A hands-on cybersecurity capstone project focused on building, configuring, and analyzing a Windows Active Directory environment. This lab explores domain administration, network enumeration, Active Directory information gathering, controlled remote-access validation, Windows endpoint analysis, and payload analysis.

## Project Objective

To gain practical experience in identifying and analyzing domain information, user accounts, services, processes, and security artifacts during an authorized security assessment.

## Tools & Technologies

- **Windows Server 2022** – Active Directory Domain Services and DNS
- **Kali Linux** – Security testing environment
- **Nmap** – Network and service enumeration
- **Metasploit Framework** – Controlled remote-access validation
- **AD Explorer** – Active Directory exploration
- **PsTools** – Windows endpoint information gathering
- **VirusTotal** – Payload analysis

## Project Tasks

1. Installing Active Directory Domain Services and DNS
2. Creating and Verifying a Domain User
3. Creating and Configuring a Shared Folder
4. Preparing the Kali Linux Testing Environment
5. Performing Network and Service Enumeration
6. Enumerating Active Directory and Domain Information
7. Generating and Executing a Controlled Meterpreter Payload
8. Exploring Active Directory with AD Explorer
9. Installing and Configuring PsTools GUI
10. Collecting and Analyzing Windows Endpoint Information
11. Analyzing the Payload with VirusTotal

## Key Learning Outcomes

- Understanding Active Directory and domain controller configuration
- Creating and managing domain users and shared resources
- Performing network and service enumeration
- Identifying Active Directory and domain information
- Exploring Windows endpoint details and running processes
- Understanding controlled remote-access testing and payload analysis
- Using security tools during an authorized lab assessment

## Project Scope

This project was performed in a controlled lab environment for educational purposes. All testing activities were intended for authorized systems only.
